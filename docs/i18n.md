# Translating the demo page

[weewx-airgradient manual](https://chaunceygardiner.github.io/weewx-airgradient/) · [weewx-airgradient on GitHub](https://github.com/chaunceygardiner/weewx-airgradient) · [Report an issue](https://github.com/chaunceygardiner/weewx-airgradient/issues)

---

As of 4.0 the demo page is translatable, entirely through WeeWX's own
mechanisms — lang files and `[Texts]`/`$gettext` — the same machinery as
WeeWX's bundled Seasons skin.  There are no invented conventions to learn:
if you have translated a WeeWX skin before, this works the same way.

![The demo page in German](https://raw.githubusercontent.com/chaunceygardiner/weewx-airgradient/master/AirGradientReport-de.png)

## How it works

Every string the page renders is a **gettext-style `[Texts]` key: the
English string is the key**.  A report falls back to English one string at
a time, so a partial translation is fine — a missing key never breaks the
page, it just renders in English.

The words come from two core-standard sources, both living in
`lang/<lang>.conf`:

| What | Where it is translated |
|---|---|
| Page title, heading, "Unavailable", the Day/Week/Month/Year tabs | `[Texts]` |
| Observation labels — the AQI heading and every plot title | `[Labels]` `[[Generic]]` (`pm2_5_aqi`, `pm2_5`, `co2`, `tvoc`, `tvocIndex`, `nox`, `noxIndex`) |

{: .note }
The skin's own `skin.conf` deliberately carries no `[Labels]`, `[Texts]` or
`[Units]` `[[Labels]]` — `lang/en.conf` is the single home for every
translatable string, and a test keeps it that way.

The concentration plots label their y axis µg/m³, which WeeWX itself
translates; the skin ships its own OpenSans fonts so that the micro sign and
the superscript three actually draw.

The lang files also localize the year plot's date axis
(`[ImageGenerator]` `[[year_images]]` `x_label_format`: day-month instead
of the US month/day).  The plots' day/date footers (`%x %X`) are drawn in
the station's own locale, not `lang` — which is why the German screenshot
above still carries US-format dates.  On **WeeWX 5.1 and later**, naming a
full locale — `lang = de_DE.UTF-8` rather than `lang = de` — localizes
those too, where the station has that locale.  On 4.6 through 5.0 the
footers always follow the machine.  Since the plots are PNG images, a
language
change appears as the images regenerate, and WeeWX redraws a plot only
once it is older than its own aggregation interval: the day plots on the
next report cycle, the week plots within an hour, the month plots within
three hours, the year plot within a day.

## Translating

**German, French, Dutch and Spanish ship with the skin** — `lang/de.conf`,
`fr.conf`, `nl.conf` and `es.conf` are complete translations of the
dictionary, each kept complete by a test, so new strings cannot ship
untranslated.  The plot-period tabs are identical to the translations of
WeeWX's own Seasons skin (a test pins them).  Corrections are welcome —
[file an issue](https://github.com/chaunceygardiner/weewx-airgradient/issues).
To use one:

```ini
[StdReport]
    [[AirGradientReport]]
        lang = de                # or fr, nl, or es
```

For any other language, the skin ships its reference dictionary at
`skins/airgradient/lang/en.conf` — every string the page renders, and
nothing else (a test keeps it exact in both directions).  To add a language:

1. Copy `en.conf` to `<code>.conf` in the same `lang` directory (e.g.
   `it.conf`) and translate the values — the keys stay English.  Translate
   as much or as little as you like; anything you drop falls back to
   English per string.
2. Point the report at it in `weewx.conf`:

```ini
[StdReport]
    [[AirGradientReport]]
        lang = it
```

Further languages are welcome as contributions — a lang file is a
self-contained, no-code contribution.

## One place for the whole station: Defaults

Anything under `[StdReport]` `[[Defaults]]` in `weewx.conf` is merged by
WeeWX into **every** report:

```ini
[StdReport]
    [[Defaults]]
        lang = de                # every skin that ships German goes German
```

`lang = de` selects each skin's own `lang/de.conf` — Seasons, this page and
any other skin that ships German switch together.  A skin with no German
simply stays English: a missing lang file is a logged no-op, never an
error.

`[[Defaults]]` (or the report's own section) is also the durable home for
local overrides: `weectl extension install` overwrites `skins/airgradient/` —
including its lang files — on every upgrade, while `[[[Texts]]]`/
`[[[Labels]]]` entries in `weewx.conf` survive and are merged over them.

## The dictionary

The reference dictionary as shipped in 4.0 (`skins/airgradient/lang/en.conf`
in the installed extension is always the authoritative copy for your
version):

```ini
[ImageGenerator]

    [[year_images]]
        x_label_format = %m/%d

[Labels]

    [[Generic]]
        pm2_5_aqi = Air Quality Index
        pm2_5     = PM2.5
        co2       = Carbon Dioxide
        nox       = Nitrogen Oxides
        noxIndex  = Nitrogen Oxides Index
        tvoc      = Total Volatile Organic Compounds
        tvocIndex = Total Volatile Organic Compounds Index

[Texts]

    "weewx-airgradient demo page" = "weewx-airgradient demo page"
    "WeeWX-AirGradient Demo Page" = "WeeWX-AirGradient Demo Page"
    "Unavailable" = "Unavailable"
    "Day" = "Day"
    "Week" = "Week"
    "Month" = "Month"
    "Year" = "Year"
```
